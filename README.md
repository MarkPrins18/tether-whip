# Tether Whip

One-thumb arcade game built with Expo (React Native) and Skia. Hold to swing on an anchor, release to fly, outrun the void.

## Install a test build on your phone
Every push to `main` builds the game on GitHub. Open **Releases**, download `tether-whip-N.apk` and install it on Android.

## Project layout
| Path | What it does |
| --- | --- |
| `src/game.js` | Game engine: physics, level generation, scoring, perfect release, shield, mines. Pure JavaScript, no UI. |
| `src/render.js`, `src/Scene.js` | Skia drawing of one frame. |
| `src/screens/` | Menu, shop, skins, missions, settings, pause, revive, game over, how to play. |
| `src/ui/kit.js` | Shared buttons, switches, toast, count-up. |
| `src/store.js`, `src/missions.js` | Save data (with migration) and the mission system. |
| `src/ads.js` | AdMob rewarded and interstitial ads, EU consent, demo fallback. |
| `src/audio.js`, `assets/sfx/` | Sound effects (generated by `tools/make_sounds.py`). |
| `config/ads.json` | Ad unit IDs. Edit this file on GitHub, no code changes needed. |
| `tools/` | Generators for sounds and icons, and the signing key scripts. |
| `docs/privacy.html` | Privacy policy (published with GitHub Pages). |
| `store/` | Store graphics and listing text. |

## Tune the gameplay
Everything lives at the top of `src/game.js`: gravity (`GR_FREE`, `GR_ROPE`), reel speed (`REEL`), max speeds, and the void speed in `stepSim`. Mine and orb frequency is in `spawnAnchor`.

## Go live on the Play Store

1. **Package name.** The id is `com.markprins.tetherwhip` (in `app.config.js`). It cannot change after you publish, so decide now.
2. **Create the upload key (once).**
   1. In your GitHub repo open Settings, Secrets and variables, Actions, New repository secret. Name `SIGNING_PASSPHRASE`, value a long random passphrase (at least 16 characters). Save it somewhere safe.
   2. Open the Actions tab, pick **Create upload key (run once)**, press Run workflow. It stores the key encrypted in `signing/upload.enc`.
   3. Never delete `signing/upload.enc` or lose the passphrase. Keep the repo private if you can.
3. **Build.** Push any change (or run **Build Android** manually). The release now contains a signed `.aab`.
4. **Ads.** Create an AdMob account, add the app, create one Rewarded and one Interstitial unit, then edit `config/ads.json`:
   `useTestAds: false`, your `androidAppId` (the `ca-app-pub-...~...` one), `rewardedUnitId` and `interstitialUnitId`. Until then the game shows Google test ads.
5. **Play Console.** Create an app, upload the `.aab` to an internal test track first, fill in the store listing (`store/listing.md`), content rating, Data safety and ads declaration, and add your own phone screenshots.
6. **Privacy policy URL.** Turn on GitHub Pages (Settings, Pages, Deploy from branch `main`, folder `/docs`). The policy then lives at `https://markprins18.github.io/tether-whip/privacy.html`.

New personal Play accounts must usually run a closed test with about 12 testers for 14 days before production access. Check the current rules in the Play Console.
